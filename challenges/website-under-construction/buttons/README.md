Try to mess around with the buttons on [this website](https://aidanlenahan.github.io/njccic9-ctf) under construction.

The homepage of the "website under construction" has a **Learn More** button. Clicking it calls JavaScript `alert()`, and the pop-up dialog shows the flag. You can also find it by reading the page source.
